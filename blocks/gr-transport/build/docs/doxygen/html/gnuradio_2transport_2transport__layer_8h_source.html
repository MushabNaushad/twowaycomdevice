18 /*!
19 * \brief Connection-oriented Selective-Repeat ARQ transport layer block.
20 *
21 * This is a **pure message-passing** GNU Radio block (no stream I/O).
22 * It implements a full connection-oriented transport protocol over a
23 * half-duplex PDU link with:
24 *
25 * - Three-phase operation: SYN/SYN-ACK handshake → SR-ARQ sliding
26 * window data transfer → FIN/FIN-ACK teardown.
27 * - Selective-Repeat windowing with sequence number space 2^m and
28 * maximum window size 2^(m-1) (SR constraint satisfied by design).
29 * - Per-packet retransmission timers via Boost.Asio on a dedicated
30 * background thread (non-blocking, flowgraph-safe).
31 * - Application bitstream header parsing (see docs/APP_BITSTREAM_FORMAT.md)
32 * to auto-detect payload type (text / image / audio).
33 *
34 * \ingroup transport
35 *
36 * Message Ports
37 * -------------
38 * Inputs:
39 * - pdu_in (message) : PDUs arriving from the physical / MAC layer.
40 * - app_in (message) : Raw application bitstream PDU from the local app.
41 * [initiator role only]
42 *
43 * Outputs:
44 * - pdu_out (message) : PDUs to be sent to the physical / MAC layer.
45 * - app_out (message) : Reassembled application bitstream delivered to
46 * the local application. [responder role only]
47 */
48 class TRANSPORT_API transport_layer : virtual public gr::block
49 {
50 public:
51 typedef std::shared_ptr<transport_layer> sptr;

54 * \brief Construct a transport_layer block.

58 * \param rto_ms Retransmission timeout in milliseconds. Default: 500.
59 * \param node_role Either "initiator" (sends data) or "responder"
60 * (receives data). Default: "initiator".
61 * \param mtu_bytes Maximum payload bytes per DATA frame. Default: 200.
62 */
63 static sptr make(int m = 4,
64 int rto_ms = 500,
65 const std::string& node_role = "initiator",
